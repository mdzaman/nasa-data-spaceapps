📘 Step-by-Step Guide — For Non-Tech Professionals

You need zero coding experience. Follow the numbers. Everything takes ~10 minutes.

1

Pick what you need

Search OrbitDB in plain English. Example: type Mars rover photos → click Search. Open any card, hit ▶ Try API to see live data. No sign-up needed.

I searched and opened a dataset
2

Get your free API key

Go to api.nasa.gov and click Generate API Key. It's free & instant (Demo: DEMO_KEY also works for trying). Save it somewhere safe.

I have my key (or will use DEMO_KEY)
3

Install Python (one time)

Go to python.org → Download → Install. Tick “Add to PATH”. Then open Terminal and run: pip install mcp httpx

Python installed + pip ran
4

Create your MCP server

Scroll to ⚡ MCP Builder above. Pick datasets, choose Python + your app. Click ⬇ Download file → save as space_mcp.py. Paste your API key in the box.

I downloaded my server file
5

Connect your AI app

In the Builder, open the ⚙️ App config tab → Copy. Open your app (Claude/Cursor/VS Code) → Settings → MCP / Servers → Paste. Restart the app.

I pasted config + restarted app
6

Test it 🎉

Ask your AI: “List the 5 NASA Mars photos from Sol 1000”. If you see structured data, you're done! See Test prompts tab for copy-paste examples.

My AI returned real data ✓

🗓️ Worked example — full journey (5 minutes)

  1. Search asteroids near Earth → open Near Earth Object Web Service card → notice endpoint + sample request.
  2. Hit ▶ Try API → click Run ▶ → watch live JSON come back. Change start_date → Run again. You just used a real NASA API.
  3. Go to MCP Builder → select Near Earth Objects + APOD + Mars Photos → client = Claude Desktop → ⬇ Download.
  4. Paste config into Claude Desktop → restart → ask: “Any asteroids this week?” → grounded, live answer with real data.

Troubleshooting: API key wrong → re-paste. Server not found → check file path is absolute. 429 error → free key rate limit (30/hr) — wait 1 min or get your own key. Still stuck? Download the full bundle and follow README.md.

❓ Help — what is this, in plain English?

OrbitDB = a search engine for space data + a plug-in builder for AI apps. No account, no code required to browse.

🔍 What is a “dataset”?

One topic NASA/ESA tracks — e.g. Mars rover photos, asteroid orbits. Each has a live API + downloads.

🔑 What is an API key?

Your free ID for NASA (api.nasa.gov). More requests than the demo. Paste it in Playground + Builder.

🔌 What is an MCP server?

A tiny “cable” between your AI app and NASA data. Your AI asks it for live data instead of guessing.

📟 stdio vs 🌐 HTTP

stdio = AI app on same computer (most people). HTTP = server on a web address (ChatGPT, cloud tools).

⌨️ Shortcuts

🆘 Stuck?

429 error → use your own key. “Server not found” → fix the file path to absolute. No tools → fully restart your AI app.
